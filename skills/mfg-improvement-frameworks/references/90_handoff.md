# 90_handoff — ステップ間の受け渡し

**道具と道具の継ぎ目だけを集めたファイル。** 各道具の使い方は `30_qc7.md` `40_n7.md` にある。
ここに書くのは、**ある道具の出力が次の道具の入力になるときの変換規則**。

道具単体を正しく使っても、継ぎ目を間違えると成果物は破綻する。
**間違いはほぼ全てここで起きる。** 図表を2つ以上またぐ作業では必ずこのファイルを読む。

## 1. 受け渡しの全体表

**各ステップの末尾に「この道具で得たもの」「次にやること」を必ず書く。**
報告資料でも教育資料でも、ここが書けないステップは実質的に飛ばしている。

| # | ステップ | この道具で得たもの | 次への入力になる形 |
|---|---|---|---|
| 1 | テーマ選定 | 重点対象の項目（パレート図の上位） | ステップ2で測る対象 |
| 2 | 現状把握 | 特性の現状値と層別結果（件数と母数） | ステップ3の目標の起点 |
| 3 | 目標設定 | 特性の裏返し＋数値＋期限 | **系統図の最上位の目的** |
| 4 | 活動計画 | 担当・期限・順序 | 実施の管理単位 |
| 5 | 要因解析 | **データで残した末端の真因**（落とした要因とその理由を含む） | 系統図の1次手段の元 |
| 6 | 対策立案 | 実行可能な対策案の一覧（系統図の末端） | **マトリックス図の評価対象全件** |
| 6 | 対策選定 | 採用案と不採用案（理由つき） | 実施計画 |
| 7 | 効果確認 | 対策前後の同一指標・同一層別の比較 | 目標との差 |
| 8 | 歯止め | QC工程表・作業標準書への反映箇所 | 日常管理（SDCA） |

### 用語は使う前に定義する

後のステップで説明する用語を、前のステップで使わない。
「真因」「管理限界」「主要因」は、**初出の箇所で1行の定義を添える。**
定義なしに使った語は、読み手の中で別の意味に置き換わる。

## 2. 特性要因図 → 系統図

**最も間違えやすい継ぎ目。** 以下を守る。

### 階層は対応しない

```
特性要因図                        系統図
─────────────────                ─────────────────
特性（右端）                 ✗→   目的
大骨（4M）                   ✗→   1次手段
中骨                         ✗→   2次手段
小骨                              3次手段
```

**この対応は誤り。** 正しくは次のとおり。

```
系統図の目的      ← ステップ3の目標（特性の裏返し ＋ 数値 ＋ 期限）
系統図の1次手段   ← ステップ5で残った末端の真因を裏返したもの
系統図の2次以降   ← その手段を実行可能なレベルまで展開したもの
```

**大骨（4M）は系統図に持ち込まない。** 4Mは要因を分類するための切り口であって、
手段ではない。「Manを改善する」という手段は存在しない。

中骨も原則として持ち込まない。データで残ったのが末端（小骨）なら、
1次手段になるのはその末端であって、その親ではない。

### 語の変換：名詞・状態 → 動詞・行動

要因は**名詞または状態**で書かれている。手段は**動詞または行動**で書く。
裏返して動詞化する。

**元の語は残す。** 言い換えると、どの要因に対する手段かの追跡ができなくなる。

| 末端の真因（名詞・状態） | 1次手段（動詞・行動） | 判定 |
|---|---|---|
| 空圧が低下する | 空圧を下げない | 可。元の語（空圧）が残っている |
| 空圧が低下する | エア供給を安定化する | 不可。「空圧」が消え、追跡が切れる |
| 治具の位置決めピンが摩耗する | 位置決めピンを摩耗させない | 可 |
| 治具の位置決めピンが摩耗する | 設備の保全を強化する | 不可。抽象化されている |
| 段取り替え後の初品確認が省かれる | 段取り替え後の初品確認を省かせない | 可 |

**否定形で止めてよい。** 「〜しない」「〜させない」は1次手段として正しい形で、
具体的な打ち手は2次以降で展開する。1次手段の段階で解決策を書き込むと、
展開が1段で終わり、いつもの対策しか出てこない。

### 絞り込んだ要因だけを展開する

**データで否定した要因には系統図を展開しない。**
展開すると、否定したはずの要因への対策が対策一覧に混ざり、
ステップ5の絞り込みが無意味になる。

出典：日科技連「新QC七つ道具の活用ポイント 第4回」（系統図は絞り込んだ主要因に対して展開する）

落とした要因は系統図には出さず、**ステップ5の記録（第4章の様式）に残す。**

## 3. 絞り込みは2回ある

**対象が違う。** 混同すると「主要因への対策だから評価不要」「案が出た時点で即採用」
という誤りが出る。

| | 1回目 | 2回目 |
|---|---|---|
| ステップ | 5 要因解析 | 6 対策立案 |
| 絞る対象 | **要因** | **手段（対策案）** |
| 絞る根拠 | データ（層別・散布図・管理図） | 評価軸（効果／実現性／コスト／副作用） |
| 使う道具 | 層別、散布図、パレート図 | マトリックス図 |
| 出力 | 残った末端の真因 ＋ 落とした要因と理由 | 採用案 ＋ 不採用案と理由 |
| 飛ばすと | 効かない対策を立てる | 実行されない対策が並ぶ |

**1回目を通ったことは、2回目を免除しない。** 主要因に対する対策であっても、
効果・実現性・コストは案ごとに違う。評価せずに採用してよい案は存在しない。

---

## 4. 絞り込みの単位は末端の要因

### 4Mは絞り込みの対象ではない

4M（大骨）は**分類の切り口**。「Machineは関係ない」という形で大骨ごと落とさない。
落とすのは**末端の要因1つずつ**。

**同じ大骨の中に、残る要因と落ちる要因が混在するのが正常。**
大骨単位できれいに残る／落ちるのは、末端まで見ていない証拠。

### 落とした理由を残す

採用理由より、**落とした理由の方が再現性に効く。**
同じ調査を次回繰り返さずに済み、対策が空振りしたときにどこへ戻るかが分かる。

| 大骨 | 末端の要因 | 判定 | 根拠 |
|---|---|---|---|
| Machine | 空圧が低下する | 残す | 号機別層別で2号機のみ不良率が高く、空圧の実測値も低い |
| Machine | 金型の温度が不安定 | 落とす | 温度と不良に相関なし（散布図 n=48） |
| Man | 段取り替え後の初品確認が省かれる | 残す | 時間帯別層別で段取り直後の1時間に集中（母数を揃えて確認） |
| Man | 新人の習熟度が低い | 落とす | 作業者別層別で差が出ず、層別で見えた条件差を説明できない |

**「層別で見えた条件差を説明できない」は正当な落とす理由。**
逆に「関係なさそう」「優先度が低い」は理由にならない。

## 5. 系統図 → マトリックス図

**評価対象は、系統図で出た対策案のすべて。**
「主要因への対策だから評価は不要」は誤り。系統図の末端に並んだ案は全件が評価対象。

| 系統図の出力 | マトリックス図での扱い |
|---|---|
| 末端の対策案 | 行に置く。**全件** |
| 途中の中間手段 | 行に置かない（実行できないため） |
| 評価軸 | 列に置く。効果／実現性／コスト／副作用（未然防止では検出しやすさを追加） |

評価記号・総合評価列の作法は `40_n7.md` のマトリックス図法を読む。

## 6. パレート図 → テーマ・目標

### 項目数は目標から逆算する

**テーマは上位1項目とは限らない。** 先に「上位N項目」と決めてから目標を置くのではなく、
**目標に届くかで項目数を決める。**

```
目標値を置く
   ↓
上位1項目を全部なくしたら目標に届くか
   ├─ 届く  → テーマは上位1項目
   └─ 届かない → 2番目を足す。それでも届かなければ3番目
```

届かないまま上位1項目に絞ると、**対策が全部成功しても目標未達**になる。
この検算を必ず行う（第7章）。

### 二段階で使う

1段目で不良項目を選び、**2段目でその項目の中身を層別してさらに絞る。**

```
1段目：不良項目別のパレート図  → 「寸法不良」が最大
   ↓
2段目：寸法不良を層別（号機別・時間帯別・機種別）→ 2号機の段取り直後に集中
   ↓
テーマ：2号機の段取り直後の寸法不良を減らす
```

1段目で止めると、テーマが「寸法不良を減らす」のままになり、
以降のステップで何を測ればよいか決まらない。

## 7. 目標 → 効果確認 → 管理図

### 部分と全体を式でつなぐ

**部分の削減件数と、全体の率の改善が計算で一致すること。**
「62件→6件」と「3.2%→1.5%」が式でつながっているかを、必ず検算する。

```
検算の形
  現状の全体率 = 全体の不良件数 ÷ 母数
  目標の全体率 = (全体の不良件数 − 対象項目の削減件数) ÷ 母数
```

つながらない場合は、目標値か削減件数のどちらかが根拠なく置かれている。

### 対象外を明示する

「その他41件は今回は触らない」と書く。書かないと、
全体率の目標が達成不能な水準に置かれていても気づけない。

### ゼロを目標にしない理由を数字で示す

対象項目を**全部なくしても到達しない水準**がある。
その場合、ゼロは目標として成立しない。到達可能な下限を計算で示す。

```
対象項目を全て0にしたときの全体率 = (全体件数 − 対象項目件数) ÷ 母数
  → この値が「今回の活動で到達しうる下限」
```

### 効果確認で見る側

管理図で改善を確認するときに見るのは**下側（LCL）**。
上振れを検出する UCL は主役ではない。詳細は `30_qc7.md` の管理図。

## 8. 受け渡しが切れているときの症状

| 症状 | 切れている継ぎ目 | 戻る先 |
|---|---|---|
| 系統図の1次手段に「Man」「Machine」が並ぶ | 特性要因図 → 系統図 | 第2章 |
| 対策一覧に、データで否定した要因への対策がある | 要因の絞り込み → 系統図 | 第2章 |
| 手段が名詞で書かれている | 語の変換 | 第2章 |
| 対策案がそのまま採用され、評価表がない | 2回目の絞り込み | 第3章・第5章 |
| 大骨ごと残す／落とすで判定している | 絞り込みの単位 | 第4章 |
| 落とした要因の理由が残っていない | ステップ5の記録 | 第4章 |
| 対策が全部成功しても目標に届かない | パレート図 → 目標 | 第6章 |
| 目標の率と件数が式でつながらない | 目標設定の検算 | 第7章 |
| テーマが「不良を減らす」のまま | パレート図の二段階適用 | 第6章 |

## 1. MECE

漏れなく、重複なく分けること。4Mをはじめとする分解軸は、MECEを製造現場向けに具体化したもの。

**実務での判断基準**

- 漏れ：挙げた要因のどれにも当てはまらない事象が思いつくか
- 重複：2つの区分に同じ内容が入っていないか

完全なMECEにこだわりすぎない。**既存の軸（4M等）を使えば実務上十分にMECEになる。**
ゼロから分類を考えるのは時間の無駄になりやすい。

## 2. 4M

最も標準的な軸。迷ったらこれを使う。

| 要素 | 意味 | 管理すべき観点 |
|---|---|---|
| **Man**（人） | 作業者 | 習熟度、勤務状況、人員の過不足、教育、モラル、モチベーション |
| **Machine**（機械） | 設備・工具 | 適合性、正常稼働、老朽化・劣化、台数、設備レイアウト |
| **Material**（材料） | 原材料・部品 | 品質、在庫の適正、仕入先、トレーサビリティ、受入方法 |
| **Method**（方法） | やり方 | 生産形態・方式、作業手順、加工条件、検査・測定方法、標準化 |

**Man が最も重要。** 他の3つも作業者の影響を強く受けるため。

### 変化点の例（4M変更管理で使う）

| 要素 | 変化点 |
|---|---|
| Man | 担当者・検査員の変更、職制変更、増員、残業、欠勤 |
| Machine | 変更、故障、異常検知、劣化、修理、交換、停電 |
| Material | 設計変更、材料変更、仕入先変更、異物混入、不良 |
| Method | 工程変更、操作方法変更、加工条件変更、保管方法変更 |

## 3. 5M＋1E / 6M

4Mでは足りない場合に拡張する。

### 5M＋1E

4M ＋ **Measurement**（計測） ＋ **Environment**（環境）

| 追加要素 | 内容 |
|---|---|
| Measurement | 計測機器の精度、測定方法・条件、測定マニュアル。測定そのものの正確性 |
| Environment | 温度、湿度、振動、明度、気圧 |

**使うべき場面**：温度・湿度で品質が変わる工程、測定値のばらつきが疑われる場合。

測定自体を疑う場合は MSA（測定システム解析）やゲージR&R分析があるが、このスキルの範囲外。

### 6M

5M＋1E ＋ **Management**（管理）

| 追加要素 | 内容 |
|---|---|
| Management | 工程・リソース配分の最適化、全体をコントロールする管理能力、中長期のマネジメント計画 |

**使うべき場面**：多品種少量で工程が複雑、部門をまたぐ問題、体制そのものが疑われる場合。

## 4. 安全工学の4M

**製造品質の4Mとは中身が違う。** ヒューマンエラー・事故・リスクアセスメントで使う。

| 要素 | 意味 | 具体例 |
|---|---|---|
| **Man**（人的要因） | 心理・生理・人間関係 | 危機感の欠如、睡眠不足、職場の人間関係 |
| **Machine**（設備的要因） | 道具・機械・設備 | 設計上の欠陥、不良、点検整備不足 |
| **Media**（作業的要因） | 作業方法・環境 | 不適切な作業方法、動作の欠陥、作業環境条件の不良 |
| **Management**（管理的要因） | 組織・体制 | 組織体制、監督体制、教育体制、健康管理、人員配置計画 |

**製造品質の4Mと取り違えないこと。** Material がなく、Media と Management が入る。

安全・労災・ヒヤリハット・ヒューマンエラーを扱うときはこちらを使う。

## 5. 3H

ヒューマンエラーが起きやすいタイミングを表す。**4Mと掛けて使う。**

| H | 意味 |
|---|---|
| 初めて | 初回、新規、経験がない |
| 変更 | やり方・条件・担当が変わった |
| 久しぶり | 間隔が空いた、しばらくやっていない |

### 4M × 3H の展開例

| | 初めて | 変更 | 久しぶり |
|---|---|---|---|
| Man | 新入社員 | 配置転換・人事異動 | 現場復帰 |
| Machine | 新設備の導入 | 設定変更・改造 | 長期停止後の再稼働 |
| Material | 新規材料 | 仕入先変更 | 長期在庫の使用 |
| Method | 新工程 | 手順変更 | 久々の受注品 |

**未然防止型のQCストーリーで最も有効な軸。** 変化点管理の土台になる。

## 6. 5E

**対策を立てる段階**で使う軸。原因分析ではなく、打ち手を広げるためのもの。

| E | 意味 | 対策の例 |
|---|---|---|
| **Education**（教育） | 教えて分からせる | 教育訓練、OJT、資格認定 |
| **Engineering**（技術） | 仕組みで防ぐ | 治具、ポカヨケ、自動化、設備改造 |
| **Enforcement**（強化・徹底） | ルール化して守らせる | 標準書化、チェックリスト、監査 |
| **Example**（模範・事例） | 手本を示す | 良品見本、事例共有、実演 |
| **Environment**（環境） | 環境を整える | 5S、照明、レイアウト、作業姿勢 |

**Education に偏りやすい。** 「教育を徹底する」だけの対策は再発しやすい。
Engineering（仕組みで防ぐ）を優先的に検討する。

## 7. QCD とその派生

**成果の評価軸。** 分解軸ではなく、テーマ選定と効果確認で使う。

| 要素 | 内容 |
|---|---|
| **Quality**（品質） | 不良率、クレーム件数、工程能力 |
| **Cost**（コスト） | 単価、原価、ロス金額、工数 |
| **Delivery**（納期） | リードタイム、納期遵守率、在庫回転 |

**3要素はトレードオフの関係にある。** 品質を追求しすぎるとコストと納期を圧迫する。
どれかに偏らず、バランスで見る。目標は必ず定量で置く。

### 派生形

| 略号 | 追加要素 | 使う業界 |
|---|---|---|
| QCDS | Service（サポート・顧客対応） | 一般 |
| QCDF | Flexibility（柔軟性） | 多品種少量 |
| QCDS | Safety（安全性） | 建設 |
| QCDSE | Safety ＋ Environment | 建設 |

## 8. 軸の選び分け

| 状況 | 使う軸 |
|---|---|
| 標準（迷ったらこれ） | 4M |
| 温度・湿度・振動が絡む／測定を疑う | 5M＋1E |
| 体制・リソース配分が絡む | 6M |
| 安全・事故・ヒューマンエラー | 安全工学の4M |
| 変化点管理・未然防止 | 4M × 3H |
| 対策を考える段階 | 5E |
| テーマ選定・効果確認 | QCD |
| データを条件で分けて差を見る | 層別キー（第9章。4Mではない） |

### 掛け合わせる相手

| 軸 | 掛ける道具 |
|---|---|
| 4M / 5M＋1E / 6M / 安全4M | 特性要因図の大骨、チェックシートの記録項目、連関図の初期カード |
| 3H | 4Mと掛けて変化点を洗い出す |
| 5E | 系統図の展開、対策案の評価 |
| QCD | マトリックス図の評価軸、目標設定 |
| 層別キー（第9章） | 層別、パレート図の二段階適用、チェックシートの記録項目 |

**層別キーを4Mから選ばせない。** 別の一覧として第9章に置いてある。

## 9. 層別キー（4Mとは別の一覧）

**層別キー ≠ 4M。** 時間帯・場所は4Mのどれにも属さないが、層別キーとしては定番。
4Mを層別キーの一覧として流用すると、この2つが最初から候補に入らない。

### 定番の層別キー

| キー | 具体例 | 記録の難易度 |
|---|---|---|
| **時間別** | 日付、曜日、時間帯、シフト、月初／月末、段取り直後 | 低 |
| **設備別** | 号機、ライン、金型、治具 | 低 |
| **作業者別** | 個人、班、経験年数、雇用区分 | 低 |
| **材料別** | ロット、仕入先、材料グレード、入荷日 | 中（トレーサビリティ次第） |
| **方法別** | 加工条件、手順バージョン、機種、段取りの有無 | 中 |
| **場所別** | 工場、棟、工程位置、保管場所、製品内の部位 | 低 |

4Mとの対応は一部だけ重なる（設備別＝Machine、作業者別＝Man、材料別＝Material、
方法別＝Method）。**時間別と場所別に対応する M はない。**

### 層別表の作法

- **必ず母数を添える。** 件数だけでは判断できない。10件／100個 と 10件／10000個 は別の話
- **どのキーで割っても、件数の合計と母数の合計が元の値と一致すること。** 一致しなければ
  分類漏れか重複がある
- **範囲表記（「11〜14件」）を使わない。** 合計が検算できず、上の一致確認ができなくなる
- 差が出なかったキーも記録する。「調べて差がなかった」は成果

記録設計（どのキーを取るか）は `60_data-design.md` 第3章。

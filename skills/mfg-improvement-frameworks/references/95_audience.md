# 95_audience — 読者と、資料に載る要素

**ここが「資料に何を載せるか」を決める唯一の場所。** 他のファイルの規則は、
考えること・言えるようにすることを要求しているだけで、**資料に書くことは要求していない。**

スキルの規則には2種類ある。混ぜると、頭で持つべきものが全部スライドに出る。

| 種類 | 例 | 行き先 |
|---|---|---|
| **思考の要求** | この道具で何が決まったか、次に何をするか、用語の意味 | **言えるようにしておく。資料に出すかは読者で決まる** |
| **成果物の要素** | 数値、層別の結果、要因、対策、管理項目 | 資料に出す |

実績：全19枚の下部に「この道具で得たもの／次にやること」のパネルを置き、
**「それは頭で考えてほしいことで、スライドに書いてほしいわけではない」**と削除指示を受けた。
用語の定義（「ネジの緩み＝トルク不足で規定トルクを保てない状態」）も同様に不要と言われた。

## 1. 読者の3種

入口の6点目で決める（`SKILL.md` 入口）。**既定値を置かない。**

| 読者 | 誰が読むか | その人が知りたいこと |
|---|---|---|
| **社内教材** | QCを学ぶ人、部内の勉強会 | **手順と道具の使い方。** なぜその道具かが主題 |
| **先方報告** | 客先、上位層、他部署の管理者 | **目標のために何をやって何を決めたか。** 手法は主題でない |
| **自分の検討メモ** | 自分、同じ案件の担当者 | 判断の履歴。後から追えること |

**先方報告で道具の説明を載せると、「それは何のためか」「不要」と返る。**
聞き手は手法を知りたいわけではない。

## 2. 資料に載る要素

| 要素 | 社内教材 | 先方報告 | 自分の検討メモ | 根拠 |
|---|---|---|---|---|
| この道具で得たもの／次にやること | 載せる | **頭で持つだけ** | 載せる | 「頭で考えてほしいことで、スライドに書いてほしいわけではない」 |
| 用語の定義 | 載せる | **その語が無いと数字が読めないときだけ** | 台帳に置く | 定義は口頭か台帳。資料の面積を使わない |
| 道具の名前 | 載せる | **最小限**（図の表題に必要な範囲） | 載せる | 手法は主題でない |
| 選ばなかった道具とその理由 | 載せる | **載せない** | 載せる | 判断の再現には効くが、聞き手の関心外 |
| 道具の手順・使い方の説明 | 載せる | **載せない** | 載せない | 教科書の再掲になる |
| やったことと決めたこと | 載せる | **載せる（これが本体）** | 載せる | 目標のためにどうするかが主題 |
| 数値・母数・層別の結果 | 載せる | 載せる | 載せる | 検算の前提 |
| 残った課題と次の一手 | 載せる | 載せる | 載せる | — |
| **何を確認してほしいか／使い方のイメージ** | 載せる | **先頭に載せる（これが本体）** | 載せる | 上司「目次と言うより、何を確認してほしいか。どんな使い方をイメージして作成しているかを伝えることが重要。相手視点で作る意識がまだ弱い」 |
| **当社からの依頼・確認事項** | 載せる | **スライド本文には載せない。ノートに置く** | 載せる | 先方に説明する資料で、社内の手続きを書く場所ではない |

**「頭で持つだけ」は、考えなくてよいという意味ではない。**
言えなければそのステップは飛ばしている。資料に書かないだけ。

## 3. 仕分け表を出す（出力必須）

**成果物（スライド・報告書・Excel の一覧・帳票・手順シート）を作る前に、この表を埋めて出す。**
文章で「先方向けなので道具の説明は省きます」と書くだけでは守られない。

```markdown
## 資料に載せる要素（読者: 先方報告）

| 要素 | 判定 | 置き場所 |
|---|---|---|
| 得たもの／次にやること | 頭で持つだけ | （口頭で言う） |
| 用語の定義（ネジの緩み） | 載せない | 台帳 |
| 道具の名前（散布図） | 図の表題のみ | スライド3-7 |
| やったことと決めたこと | 載せる | 全枚 |
```

- **既定は「頭で持つだけ」。** 載せる判断をしたものだけが資料に出る
- この表は**作業用**。先方向けの資料には載せない
- 読者が変わったら作り直す。同じ内容で読者だけ変えるときも、**必ず引き直す**

### 置き場所は4つ。配布前にノートを消す

| 置き場所 | 何を置くか | 配布のとき |
|---|---|---|
| スライド本文・シート | やったことと決めたこと、数値、**何を確認してほしいか** | そのまま渡す |
| **ノート（スピーカーノート）** | **口頭で言う補足、質問、当社からの依頼、検算の件数、社内の判断、個人の発言。既定はここ** | **配布前に全ノートを消す** |
| 社内の作業メモ（別ファイル） | 設計の履歴、確認の経緯、残作業 | 渡さない |
| 台帳 | 用語の定義、言葉の台帳 | 渡さない |

- **ノートに書くことを制限しない。** 制限すると口頭の補足が書けなくなる
- **成果物を渡す段で「ノートを消したか」を確認する。** これを工程として持つ。
  実績：ノートに検算の件数と先方の室長の過去の発言が入っており、**上司が全ノートを空にした。**
  **書いたことが問題ではなく、消す工程が無かったことが問題**
- **配布方法（pptx のまま渡すか、PDF にするか）を、渡す前に確認する**

### 先頭に「何を確認してほしいか」を置く

**手順や目次を並べるだけにしない。** 読者は、何を見てどう反応すればよいかが分からない。

| 置くもの | 書き方 |
|---|---|
| 何を確認してほしいか | 「この形で認識が合っているか」「空欄に記入いただけるか」など、**読者の動作**で書く |
| どんな使い方をイメージしているか | 「会議の前に該当の行だけ見る」など、使う場面で書く |
| **題名** | **上司・利用者が付けた名前をそのまま使う。** 言い換えたら言葉の台帳に「要確認」で載せる |

実績：手順シートに**「手順になってない」「あなたが勝手に作ったものです」**と返り、
題名の指摘が**3回**繰り返された。

## 4. 先方報告のときの書き方

- **1枚のメッセージは「やったこと」か「決めたこと」。** 「パレート図で分析した」ではなく
  「不良の7割がネジの緩みとはんだ不良に集まっている」
- 図の表題は**何を決めるための図か**を書く（道具名だけにしない）。
  道具名は表題の補足として最小限に入れる
- 用語を出さずに書けるなら出さない。出すなら、定義ではなく**その語で何が変わるか**を書く
- 手順の全通し（8ステップを1枚ずつ）は社内教材の作法。
  先方報告では、**決めたことの並びで組む**（`00_mapping.md` 第5章）

### 読者の設定は、主語と依頼の置き場所にも効く

**読者を決めただけでは、書き方は決まらない。** 載せる／載せないの仕分けだけでなく、
**誰の視点で書くか**まで落とす。

| 守ること | 実績 |
|---|---|
| **主語は読者から見た形にする。** 当社の内部手続きを第三者の言い方で書かない | 「使ってよいか、先方に確認する」と書き、**「先方に説明する資料で、社内用ではない」**と返った |
| **当社からの依頼・質問は資料に書かず、口頭の質問（ノート）に置く** | 同上。依頼事項の枚を作ると、報告が依頼書になる |
| 用語の難しさも読者に合わせる | 社内でしか通じない略語・帳票名は、読者が使う語に置き換える |

- 悪い：「この指標を使ってよいか、先方に確認する」（読者＝先方なのに、先方を第三者として書いている）
- 良い：資料には「今使える指標は72件」と事実を書き、**使用の可否は口頭で確認する**

### 用語と抽象語は、案件の文脈から決める

**用語の定義を資料に載せるかは第2章の表で決まる。** ここは**自分が言えるようにする側**の規則。

| 守ること | 実績 |
|---|---|
| **用語の定義は案件の文脈から引く**（OP表のインプット／アウトプット、Excelの列名、過去資料の言い回し） | 「前に準備するもの／次へ渡すもの」と言い換えて**「わかりにくい。今までのMTGやプロジェクト内容を把握しなおして」**と返った。過去資料の語を、定義を確認せずに流用していた |
| **動詞を段階に合わせる** | 現状把握の段で「定義する」と書き、**「現状把握が目的なので言わないで」**と返った |
| **新しい区分は、数字の前に1行で説明する** | 「不明」という区分を説明なしに数字で出し、**「最初に説明はすべき」**と返った |
| **抽象的な動詞句には具体例を添える** | 「何を見て、何の数字で測るかが決まるように」に**「分かりにくい」**と返った。利用者は**「例はわかりやすいので、載せてもいい」**と述べている |

**過去の資料の言い回しを使うときは、その語が何を指すかを現物（OP表・Excelの列）で確かめる。**
確かめずに使うと、読者の持っている定義とずれる。

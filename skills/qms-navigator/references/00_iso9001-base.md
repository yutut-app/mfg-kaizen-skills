# 土台 — ISO 9001:2026 の条項地図

**既定は 2026 年版（2026-09-16 発行）。** 旧版の 2015 年版は、差分を確かめるためだけに持つ。

## 版の扱い

| 状況 | 扱い |
|---|---|
| 通常 | **2026 年版で判定する** |
| 自動車（IATF 16949:2016）| 2026 年版で判定する。ただし IATF 16949:2016 の認証審査は、IATF 第2版（2027年予定）が出るまで 2015 年版を土台に行われる。**下の差分表の条項では「IATF 審査は 2015 基準」と注記する** |
| 相手が 2015 年版で認証を受けている | 2026 年版で判定し、差分表の条項は「相手は 2015 認証（2029-09-30 まで有効）。移行時に求められる」と注記する。**2015 認証の範囲で抜けとは言わない** |

## 2015 年版からの差分（公開情報、2026-09-28 確認）

移行期間は3年で、2015 年版の認証は 2029-09-30 に失効する。改訂は小幅で、枠組み（プロセスアプローチ、4〜10章の構成）は変わらない。
**出所は認証機関の解説（[DQS](https://www.dqsglobal.com/en/explore/focus-area/iso-9001-revision-at-a-glance)、[TÜV Rheinland](https://www.tuv.com/world/en/revision-iso-9001-2026.html)、[SGS](https://www.sgs.com/en/showcases/iso-9001-2026-key-updates-and-transition-guidance)）で、規格本文では照合していない。** 細かい番号は解説の間で食い違いがある。下の条項表には反映済みで、該当行に【26】と印を付けた。

| 箇所 | 2026 年版で変わった点 | 確かさ |
|---|---|---|
| 4.1 / 4.2 | 気候変動が関連する課題か、利害関係者の要求に含まれるかを考える（2024年の追補を取り込み） | 複数の情報源 |
| 5.1 | トップマネジメントが**品質文化と倫理的な行動**を推進する | 複数の情報源 |
| 5.2 | 品質方針を、組織の状況と**戦略的な方向性**に合わせる | 単一の情報源（番号は未確認） |
| 6.1 | **リスクへの取組み**と**機会への取組み**を別の細分箇条に分けた（6.1.2 / 6.1.3 とする解説あり） | 分割は複数、番号は単一 |
| 7.3 | 認識の対象に**品質文化と倫理的な行動**が加わる | 複数の情報源 |
| 全体 | 他の ISO マネジメントシステム規格と共通の構造（調和構造）に合わせた。附属書 A（参考）は全面改訂 | 複数の情報源 |

**すべて未照合（知識による要約）。** 規格書で照合したら、行の「照合」列を「済」にする。
本文は転載しない。見出しは要旨、要約は自分の言葉。

## 条項の表の読み方

| 列 | 中身 |
|---|---|
| 条項 | 番号。**番号が判定の根拠になるので、曖昧なら使わない** |
| 要旨 | 何を求めているか |
| 証拠 | 審査で「見せてください」と言われやすいもの。**文書化した情報**（記録・手順）が要求される所に ◎ |
| 突かれやすい所 | 形式だけで満たしたつもりになりやすい点 |

全体の考え方（どの条項にも効く）：

- **プロセスアプローチ**：仕事をプロセス（入力→活動→出力）として定め、つなぎを管理する
- **リスクに基づく考え方**：予防処置という独立の条項は無く、計画段階（6.1）に吸収されている
- **PDCA**：4〜6 章が Plan、7〜8 が Do、9 が Check、10 が Act に概ね対応する
- 「文書化した情報を維持する」＝手順などの文書、「保持する」＝記録、と読み分ける

## 4 組織の状況

| 条項 | 要旨 | 証拠 | 突かれやすい所 |
|---|---|---|---|
| 4.1【26】 | 内外の課題を把握する。気候変動が関連する課題かを考える | 課題の一覧、見直しの跡、気候変動の検討結果 | 作っただけで更新されていない。気候変動を「該当なし」とだけ書き理由が無い |
| 4.2【26】 | 利害関係者と、その要求を把握する（気候変動に関する要求を含みうる） | 利害関係者の一覧 | 顧客以外（法規制当局・仕入先）が抜ける |
| 4.3 | QMS の適用範囲を決める | ◎適用範囲。適用除外の理由 | 設計を除外しているのに実は設計している |
| 4.4 | プロセスとそのつながりを定める | プロセスマップ、指標、責任者 | プロセスごとの指標・監視が無い |

## 5 リーダーシップ

|---|---|---|---|
| 5.1【26】 | トップが QMS に責任を持つ。顧客重視。**品質文化と倫理的な行動を推進する** | マネジメントレビュー記録、方針展開、品質文化の取組み | トップが説明できない。品質文化が標語だけ |
| 5.2【26】 | 品質方針を定め、伝える。組織の状況と戦略的な方向性に合わせる | ◎品質方針 | 現場が方針を言えない。方針が事業戦略とつながっていない |

## よく混同される区別

| 区別 | 違い |
|---|---|
| 修正 と 是正処置 | 修正は起きた不適合の手当て（選別・手直し）。是正処置は原因を除いて再発を防ぐこと |
| 検証 と 妥当性確認 | 検証は「仕様どおりに作ったか」。妥当性確認は「意図した用途で使えるか」 |
| 維持 と 保持 | 維持は文書（手順）、保持は記録 |
| 特別採用 と 手直し | 特別採用は不適合のまま使う許可。手直しは要求に適合させること |

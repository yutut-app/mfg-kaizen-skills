# 他スキルとの受け渡し

| 話がこう移ったら | 渡す先 | 渡すもの |
|---|---|---|
| 不良・是正処置で、**原因そのものを分析したい** | `mfg-improvement-frameworks` | 不適合の内容、関係する条項（10.2 等）、この件で求められる証拠（有効性確認・水平展開） |
| 抜けの一覧を**報告資料にしたい** | `slider-craft` | 出力の表、相手、優先して対処するもの |
| コアツール文書を**作りたい**（FMEA を書く、コントロールプランを起こす） | 範囲外 | 作成は先方または担当部署の仕事と伝える。このスキルは出来上がった物を読む側 |
| 表を Excel で配りたい | `anthropic-skills:xlsx` | 出力の表 |

**戻ってくるとき**：改善スキルで対策が決まったら、ここに戻り、是正処置として要求（10.2、自動車なら 10.2.3〜10.2.4、FMEA・コントロールプランへの反映）を満たしているかを検査する。

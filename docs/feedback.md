## 棚卸しのやり方

1. 未対応の行を眺め、**同じ原因が2回以上出ているもの**を優先する
2. 1回だけの事象は原則そのまま置く（n=1で書き換えると別ケースを壊すため）
3. 修正案を Claude に出させ、内容を確認してから適用する
4. `metadata.version` / `plugin.json` / CHANGELOG / git tag を揃える
5. チャットにも配布済みなら、ZIPを作り直してアップロードし直す

# 改善ログ

`mfg-improvement-frameworks` を使っていて期待どおりに動かなかったケースを記録する。

- 記入は Claude が自動で行う（SKILL.md の改善プロトコルに従う）
- **このログへの追記だけを自動で行い、SKILL.md 本体は勝手に書き換えない**
- 月1回、または5件たまったタイミングで棚卸しし、反映するかを人が判断する
- 反映済みの行は「対応」欄に版数を書く（例: `v1.1.0で修正`）

## 棚卸しのやり方

1. 未対応の行を眺め、**同じ原因が2回以上出ているもの**を優先する
2. 1回だけの事象は原則そのまま置く（n=1で書き換えると別ケースを壊すため）
3. 修正案を Claude に出させ、内容を確認してから適用する
4. `metadata.version` / `plugin.json` / CHANGELOG / git tag を揃える
5. チャットにも配布済みなら、ZIPを作り直してアップロードし直す

# 改善プロトコル（SKILL.md 末尾に組み込む定型ブロック）

このリポジトリの全スキルの SKILL.md 末尾に、以下をそのまま貼る。

---

```markdown
## 改善プロトコル

このスキルの手順どおりに進められなかった場合、または利用者から選定・出力への
指摘を受けた場合、以下を順に行う。

1. `docs/feedback.md` の表に1行追記する（日付／依頼の要約／期待した挙動／
   実際の挙動／推定原因）。追記はこのファイルに対してのみ行う。

2. SKILL.md および references/ は**この時点では書き換えない**。

3. 利用者から明示的に修正を求められた場合のみ、次の順で進める。
   - どこをどう直すかを**先に提案し、承認を得る**
   - 承認後に書き換え、変更点を報告する
   - 同じ原因が過去に2回以上記録されているかを `docs/feedback.md` で確認し、
     1回限りの事象であればその旨を添えて慎重な判断を促す

4. `docs/feedback.md` が存在しない、または書き込めない環境（チャット等）では
   何もしない。エラーを報告せず、代替手段も取らない。
```

---

## 設計意図

| ルール | 目的 |
|---|---|
| 追記のみ自動 | 一番面倒な「気づきの記録」だけを自動化する |
| 本体は書き換えない | 1回の失敗が永久ルールになる事故を防ぐ |
| 提案→承認→書き換え | 差分レビューを必ず人が通す |
| n=1への注意喚起 | 過剰一般化による劣化を防ぐ |
| チャットでは沈黙 | 書き込めない環境で余計な挙動を出さない |

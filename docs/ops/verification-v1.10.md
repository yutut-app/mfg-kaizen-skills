## 2. 合否基準（R1〜R10）

**判定は4値。** `40_test.md` 2 に従う。

| 値 | 意味 |
|---|---|
| 合格 | 基準を満たした |
| 不合格 | 満たしていない。**満たしていないことが出力で確かめられた** |
| **判定不能** | 出力からは判断できない。**合格に数えない** |
| 対象外 | その試験には当てはまらない基準（理由を書く） |

| 区分 | 扱い |

| **要確認** | 外れて見えるが正しい可能性がある。人が見る。**主張の当否はすべてここ** |

### 追加の入力（E4）— R10 が空振りしたため

手順0では、機械的な分類が発生する入力が無く R10 を判定できなかった。**手順6の前に E4 を足す。**

```
点検項目の一覧（Excel）を渡します。180行あって、「点検内容」の列の文言から
自動で「数値を測るもの／目視で見るもの／どちらとも読めないもの」に振り分けてほしい。
そのうえで、客先に出す現状報告の2枚目に使える表にして。
```

R10 の判定：振り分けた結果に**定義（どの条件でその区分に入れたか）・例（現物の表記のまま1〜2件）・暫定であることの明示**が付いているか。

## 4. この回の限界（正直に残す）

- **F2（E6）は測れていない。** 呼ばれ方の試験は**基盤側のエラー（`[reasoning_extraction]`）で5回落ちた**。
  Opus・Sonnet の両方で同じ。**3種のうち2種でしか測っていない**
- **手順0 の基準値は、同じ入力の前後比較が1件（E5）だけ。** 残りは実運用の記録
  （Excel 案件で呼び出しのログが無かった事実）に依拠する
- **1回目の応答のみ。** 2ターン目以降（原文を受け取った後に、台帳が本当に埋まるか）は未検証。
  **ここが次の検証の対象**
- **「利用者の言葉で書けているか」は機械で測れない。** 台帳は「出所が書かれているか」
  「言い換えに要確認が付いているか」までしか担保しない
- 実物（第12回資料・Excel Rev1〜5）と記憶3件の本文は見ていない
